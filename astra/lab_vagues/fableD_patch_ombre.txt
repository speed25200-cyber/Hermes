  - Journalise chaque trade virtuel dans data/ombre-inverse.jsonl

      v2     = INV s>=2 · vol>=2.5×méd24h · accord range-24h · tp80/sl30/act25/cb15/hold12

      fablew = v2 + filtre ret1h contre · act20/cb20 (angle winrate)
    Verrou 12 h/instrument (144 bougies), levier 15, coûts 0,12 %, entrée à l'OPEN
    de la bougie 5 m suivante — sémantique STRICTEMENT identique au banc v3
    (validé par lab_vagues/fableD_replay_test.js : 427/427 trades reproduits à
    1e-9 près, 0 écart inexpliqué, restart 7/7).
  - Persistance : au redémarrage de l'app, les positions papier ouvertes et les
    verrous sont restaurés depuis le journal (événement OMBRE_BOOT avec
    positionsRestaurees).

/* === FABLE D — OMBRE INVERSE (ancienne stratégie) : trades PAPIER uniquement ===
   Journal : data/ombre-inverse.jsonl · kill-switch : HERMES_OMBRE=off puis restart.
   Aucun ordre, aucun appel privé : le module ne touche ni AI.*, ni le budget,
   ni les 13 stratégies HERMES15. Formule et validation : lab_vagues/fableD_*. */
(() => {
  try {
    if (String(process.env.HERMES_OMBRE || "on").toLowerCase() === "off") { log("[OMBRE_INV] désactivé (HERMES_OMBRE=off)"); return; }
    const ombreInverse = require(path.join(ROOT, "lab_vagues", "fableD_ombre_inverse.js"));
    ombreInverse.demarrer({ MARKET, DATADIR, log });
    globalThis.__fableD_ombre = ombreInverse;
  } catch (e) { try { log("[OMBRE_INV_ERR]", e.message); } catch {} }
})();

ALTERNATIVE au BLOC A (si l'on refuse de toucher au corps du gate) : BLOC A'

/* === FABLE D — OMBRE INVERSE : émission des signaux sans éditer le gate === */
(() => {
  try {
    if (!globalThis.__fableD_ombre) return;
    const __occ_avant_ombre = onCandleClose;
    onCandleClose = function (instId, candle) {
      __occ_avant_ombre(instId, candle);
      try {
        const hist = MARKET.candles[instId]?.getHistory() || [];
        if (hist.length < 8) return;
        const { score, dir } = computeScore(hist);
        globalThis.__fableD_ombre.onSignal(instId, dir, score);
      } catch {}
    };
  } catch (e) { try { log("[OMBRE_INV_ERR]", e.message); } catch {} }
})();

(Le gate V2 est une IIFE SYNCHRONE exécutée au chargement : un bloc ajouté en fin
de fichier enveloppe donc bien la version gate de onCandleClose, pas l'originale.)

RAPPELS D'IMPLÉMENTATION (pourquoi c'est fidèle au banc, zéro look-ahead)
--------------------------------------------------------------------------------
- Bougies 5 m : lues depuis MARKET.bars5m (WS candle5m + préfill REST 200). La
  clôture d'une bougie = apparition de la bougie suivante ; la décision n'utilise
  QUE la bougie close et les 288 closes précédentes ; le prix d'entrée est l'OPEN
  de la bougie suivante (premier prix postérieur à toute l'info).
- Médiane volume 24 h et range 24 h : fenêtre de 288 bougies closes contiguës
  (garde de contiguïté + garde 289e bougie, comme le banc) ; si l'historique est
  court au boot, backfill REST public (300 bougies, 1 instrument / 1,5 s, max 50
  en file, uniquement les instruments réellement signalés).
- Verrou 12 h : en BOUGIES (nouvelle entrée seulement si open > dernière entrée
  + 144×5 min), persistant à travers les restarts.
- Sorties : SL testé avant TP dans la bougie (pire-cas), trail sur les CLOSES,
  HOLD au close de la 144e bougie après l'entrée, GAP = sortie au dernier close
  connu si une bougie manque — exactement le simulateur du banc v3.
- PAS d'ordres : la phase ARMÉE éventuelle (plus tard, avec OK client) passerait
  par globalThis.__hermesEntre(instId, side, ov) avec
  ov = { tpPctMargin:0.80, slPctMargin:0.30, trailActPctMargin:0.25,
         trailCbPctMargin:0.15, holdMs:12*3600e3 }
  (mêmes sorties posées SUR OKX via le gate), en excluant les instruments des 13
  stratégies HERMES15 et en laissant canPlaceOrder appliquer budget/10 positions.
  Ceci N'EST PAS inclus dans ce patch.
